CLI 安装

适合命令行用户与自动化部署，步骤最短。

# === 系统与 Python 3.11 === sudo apt update sudo apt install -y software-properties-common sudo add-apt-repository -y ppa:deadsnakes/ppa sudo apt update sudo apt install -y python3.11 python3.11-venv python3.11-dev python3-pip build-essential git curl # === 项目与虚拟环境 === mkdir -p ~/openakita && cd ~/openakita python3.11 -m venv venv source venv/bin/activate pip install -U pip setuptools wheel # === 安装 OpenAkita === pip install "openakita[all]" \ -i https://mirrors.aliyun.com/pypi/simple/ \ --trusted-host mirrors.aliyun.com # === 初始化与运行 === openakita init --quick openakita # === 测试 === openakita run "你好，介绍一下你自己"

系统要求

项目说明
系统Ubuntu 22.04 LTS Server（已联网）
权限具备 sudo 的普通用户
Python3.11+（本教程固定使用 3.11）
API Key至少配置一个 LLM 提供商密钥
磁盘推荐 20 GB 及以上

Docker 安装

适合 Server 容器化部署，克隆项目、配置 API Key 后一键构建启动。

# === 克隆项目 === git clone https://github.com/openakita-io/openakita.git && cd openakita # === 配置环境变量 === cp .env.example .env nano .env # === 只需修改这一行 === DASHSCOPE_API_KEY=sk-你的密钥 # === 启动服务 === sudo docker compose build sudo docker compose up -d # === 验证运行 === sudo docker compose ps # === 访问 OpenAkita === # 浏览器打开：http://<本机IP>:18900

源码安装

适合需要二次开发、定制构建和自托管流程的团队。

# 1) 拉取源码 git clone https://github.com/openakita/openakita.git cd openakita # 2) 创建并激活虚拟环境 python -m venv venv source venv/bin/activate # 3) 以开发模式安装（含 dev 依赖） pip install -e ".[all,dev]" # 4) 准备运行配置文件 cp examples/.env.example .env cp data/llm_endpoints.json.example data/llm_endpoints.json # 5) 初始化并生成目录 openakita init
