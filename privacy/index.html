Browser chat / 网页对话

On openakita.ai, Web Chat sends your API key and conversation directly from your browser to your selected LLM provider to generate responses. These requests do not pass through OpenAkita servers. When "Remember API key on this device" is enabled, saving an endpoint stores its key unencrypted in this browser's localStorage. Otherwise, the key stays only in tab memory. Disable this option and save, delete the endpoint, or clear site data to remove a stored key. Conversation history and endpoint metadata also stay in this browser. You can export or delete conversations in Web Chat; exports do not include API keys. Your provider's data retention and privacy policies apply to the requests it receives.

openakita.ai 网页对话由浏览器直接向你选择的 LLM 供应商发送 API Key 和对话，以生成回答。这些请求不经过 OpenAkita 服务器。启用“在此设备上记住 API Key”后，保存端点会将密钥以未加密形式保存在当前浏览器的 localStorage 中；关闭该选项时，密钥仅保留在标签页内存。关闭该选项后保存、删除端点或清除站点数据，可以移除已保存的密钥。聊天记录和端点信息也保存在当前浏览器，对话可以删除或导出，导出文件不包含 API Key。供应商收到的数据适用其隐私与数据保留政策。
